## Flue 2.2.2

- `setProvider(provider)` — `models.setProvider`, replaces any provider with the same id (`dist/providers-*.mjs`).
- Runtime `Models` is `createModels()` with **no credential store** → built-in OAuth providers never resolve credentials. Hence `@fluex/pi-auth`.
- Built-in registration never overwrites a registered id: `registerDefaultProviders()` and `registerBuiltinProviderModule()` both skip ids where `hasProvider(id)`. Calling `setProvider` at agent-module top level is therefore safe under `flue run` regardless of evaluation order. Generated by `@flue/vite` as `virtual:flue/providers`.
- `start({ providers?: readonly Provider[] })` (`@flue/runtime/node`).
- `@flue/runtime/internal` exports `hasProvider`, `resetModelsForTests` (used in tests only).
- `SandboxDiedError` constructor takes `{ operation: string; reason: 'probe_silent' | 'stopped' }` — **not** a message string (the original handoff sketch was wrong).
- `SandboxDriver` keys: `readFile, readFileBuffer, writeFile, stat, readdir, exists, mkdir, rm, exec` (asserted in `packages/pi-auth/test/flue-contract.test.ts`).
- `flue init --target node` scaffolds `flue.config.ts`, `src/agents/*.ts` (`'use agent'` directive; exported capitalized functions are agents), `src/db.ts` (`sqlite('./data/flue.db')`), `.env`.
- `flue run <path> --message <text>`.

## pi-ai 0.87.1

- Export subpaths: `.`, `./providers/*`, `./api/*`, `./utils/*`, `./oauth`, `./compat`, `./bedrock-provider`, `./bun-oauth`. `auth/oauth/load.js` is not exported — reach OAuth flows via `provider.auth.oauth`.
- `Provider` is a plain object from `createProvider` with own `stream`/`streamSimple`/`getModels`; `Provider.api` is **not** a property. Spreading a built-in provider and replacing `auth` keeps its catalog and streaming.
- `ProviderAuth = { apiKey?: ApiKeyAuth; oauth?: OAuthAuth }`.
- `ApiKeyAuth.resolve({ ctx, credential?, signal }) → AuthResult | undefined`; optional `check()`.
- `OAuthAuth.refresh(credential, signal)` — **takes a signal** (the original handoff sketch omitted it); `toAuth(credential) → ModelAuth`.
- pi-ai refreshes OAuth tokens with < 5 min validity (`DEFAULT_OAUTH_MINIMUM_VALIDITY_MS`).
- `openaiCodexProvider()`: OAuth only, baseUrl `https://chatgpt.com/backend-api`, `toAuth → { apiKey: credential.access }`, refresh credential includes `accountId`.
- `openai-codex` model ids: `gpt-5.3-codex-spark gpt-5.5 gpt-5.6-luna gpt-5.6-sol gpt-5.6-terra gpt-6-astra gpt-6-luna gpt-6-sol`. The handoff's `gpt-5.4-mini` no longer exists. pi's own default (`~/.pi/agent/settings.json`) is `gpt-5.5`.
